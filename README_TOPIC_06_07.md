# Данные как основа ИИ — темы 6 и 7

Содержание новых занятий размещено в `/read/06.html` и `/read/07.html`. Из `index.html` доступны лонгриды, лабораторные, тренажёры и учебные файлы. Сайт статический и может работать на GitHub Pages.

**Тема 6:** распределения, описательные статистики, пропуски и выводы ИИ.  
**Тема 7:** корреляция, разрезы по группам, смешивающие факторы и проверка причинных утверждений.

В комплект включены лекционные тексты, лабораторные с тремя равноправными маршрутами, CSV-данные, табличный практикум XLSX, Jupyter-ноутбуки, интерактивы, PDF/TeX-презентации, 12 вопросов GIFT на каждую тему и сценарии занятий.

### Как проверить локально

Откройте `index.html` или запустите в корне репозитория:

```powershell
python -m http.server 8000
```

Затем перейдите по адресу `http://localhost:8000/`.

В работе не используется серверный код, авторизация и платные ИИ API. Для самостоятельных заданий можно работать с готовыми черновиками ответов ИИ, если у студента нет доступа к модели.

### Публикация в существующий репозиторий

Распакуйте ZIP-архив в отдельную папку, скопируйте содержимое в корень клона `data-ai-sem2`, выполните `git add -A`, `git commit` и `git push`. Изменения вносятся в `index.html` и `resources.html`; темы 4–5 сохраняются.
