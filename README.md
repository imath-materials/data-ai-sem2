# Данные как основа ИИ · темы 4–5

Открытая версия учебного сайта: два интерактивных лонгрида, тренажёры, практикумы, материалы занятия и примеры данных.

## Разделы

- `index.html` — начало курса и навигация.
- `read/04.html`, `read/05.html` — интерактивные лонгриды для самостоятельного изучения.
- `04_ИНТЕРАКТИВЫ/` — тренажёры с обратной связью после ответа.
- `03_ЛАБОРАТОРНЫЕ/` — лабораторные задания и варианты маршрутов.
- `05_ДАННЫЕ_СТУДЕНТАМ/` — файлы для практик.
- `06_JUPYTER/` — тетради для программного маршрута.
- `09_ПРЕЗЕНТАЦИИ_PDF/` — очные занятия.
- `08_ПРЕЗЕНТАЦИИ_TEX/` — исходники слайдов.
- `01_ПРЕПОДАВАТЕЛЮ/` — методические материалы без закрытых эталонных ответов.

## Открыть локально

Откройте `index.html` в браузере. Для некоторых локальных функций удобнее запустить веб-сервер из корня папки:

```powershell
py -m http.server 8000
```

Откройте `http://localhost:8000/`.

## GitHub Pages

Опубликуйте содержимое этой папки в корень репозитория. В Settings → Pages выберите Source: Deploy from a branch, Branch: `main`, Folder: `/(root)`.

Ответы преподавателя не входят в этот репозиторий. Не добавляйте сюда студенческие работы, персональные данные, секреты, API-ключи и закрытые материалы.
