Данные как основа ИИ: место тем 4–5 в курсе

Результат двух тем

Студент умеет получать из неоднородных измерений проверяемый массив и строить два осмысленных представления данных для разных задач. Он может объяснить каждый спорный шаг, обнаружить неправильную рекомендацию ИИ и воспроизвести преобразования доступным ему инструментом.

Зафиксированные требования нового плана

Тема 4: обработка пропусков, дублей, форматов и ошибок, фильтрация, объединение наборов. Работа без ИИ и при поддержке ИИ, причём результат сравнивается с исходным. Тема 5: типы данных, кодирование категорий, масштабирование/нормализация, создание производных признаков и выбор способа представления под задачу. В семестре в целом — проверки результатов ИИ и знакомство с многошаговыми аналитическими процессами.

Что делает эти материалы новым бакалаврским продуктом

  1. Единый предметный конфликт: исправление данных способно скрыть аварийный сигнал, а неподходящее представление — придумать ложное сходство.
  2. Два разных вида проверки: в теме 4 — происхождение и корректность записи; в теме 5 — смысл и целевое назначение признака.
  3. Вариативность по сути работы: таблицы для прикладных направлений, воспроизводимый код для программных, методологическая проверка для исследовательских.
  4. Необязательность LLM-сервиса: предусмотрены реалистичные ошибки готового ИИ-плана, поэтому можно учиться аудиту и без API.
  5. ИИ — сквозной инструмент, агент — следующий этап: не требуется собирать автономную систему во втором семестре; в пятом семестре возможен переход к архитектурам и инструментальному управлению.
  6. Контекст университета: синтетические данные учебных помещений, охватывающие события, измерения, справочники и естественно-языковые обращения. Данные не связаны с реальными студентами.

Связь с предшествующими материалами магистратуры

Сохраняются удачные педагогические ходы из ранее обсуждённого магистерского курса: паспорт исходных данных, работа с несколькими форматами, диагностика проблем, журнал «до/после», подготовка признаков, сочетание Code и No Code, критическая проверка ИИ. Не переносятся магистерские лабораторные, сюжет, последовательности шагов и требования к владению ML-инструментами.

Операционные границы

Учебные пороги показаний в синтетическом кейсе не являются санитарными нормами. Нет реальных персональных данных. Исходники сохраняются. Внешняя LLM необязательна.
