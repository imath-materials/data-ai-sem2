# Темы 6–7. Структура Moodle

Каждая тема включает четыре разные учебные активности:

1. **Интерактивный лонгрид** — подготовка до занятия. В нём студент принимает решения и видит последствия.
2. **Очная лекция/разбор** — формулы, границы применимости, коллективное обсуждение ошибок.
3. **Тренажёр самопроверки** — повторяемые задачи без баллов. Для Moodle подготовлены файлы GIFT по 12 вопросов.
4. **Лабораторная** — работа с собственным результатом, расчётами и проверкой ИИ; отдельно оценивание по общей рубрике на 10 баллов.

Для автономного HTML-тренажёра используйте файл `Тренажер_06.html` или `Тренажер_07.html` вместе с `assets/topic67-quiz-data.js`, `assets/topic67-quiz.js`, `assets/site.css` и `assets/topic67.css`. При прямой вставке JS в обычную Moodle-страницу выполнение скриптов может быть ограничено настройками безопасности: удобнее ссылаться на опубликованный статический сайт или использовать разрешённый способ интеграции.

**GIFT:** импортируйте текстовые файлы `Тема_06_12_вопросов_GIFT.txt` и `Тема_07_12_вопросов_GIFT.txt` как банк вопросов. Чтобы использовать их для неоцениваемой тренировки, настройте тест в Moodle без учёта в итоговой оценке, с обратной связью и несколькими попытками. Сам по себе GIFT не отключает начисление баллов.

**Что не публиковать студентам:** отдельный преподавательский пакет с точными эталонными значениями и проверочным протоколом. Публичные лонгриды и тренажёры не содержат скрытых отметок или учёта прогресса на сервере.
